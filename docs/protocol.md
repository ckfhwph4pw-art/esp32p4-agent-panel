# 通信协议

## 传输层

USB CDC（TinyUSB），虚拟串口。不需要波特率协商，但采集端仍以 115200 打开端口，
因为 pyserial 需要一个值。

板子同时监听 UART0（控制台）与 USB CDC 两条通道，两路共用同一个行处理函数，
用互斥量串行化。日常使用走 USB；UART 那条保留给调试。

## 消息格式

行分隔 JSON（NDJSON），一行一条，UTF-8。

```json
{"ag":"workbuddy","st":"busy","task":"执行命令","cmd":"cat >> notes.md","ago":"0 秒前","el":128,"cnt":396,"csub":"今日操作","sub":"会话 4 个","heat":"000000000000011000009033"}
```

采集端使用紧凑分隔符（`,` 与 `:` 之间无空格），单行约 60 至 120 字节。

## 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ag` | string | 是 | 标识：`pc` / `workbuddy` / `hermes` / `deepseek`。未知值会被忽略 |
| `st` | string | 是 | 状态：`busy` / `idle` / `wait` / `off`。其它值按未知处理 |
| `task` | string | 是 | 中文短语，描述当前动作，显示在任务行 |
| `cmd` | string | 否 | 命令摘要，显示在任务行下方，单行省略 |
| `ago` | string | 否 | 距最后一次检测到活跃的可读时长，如 `25 分钟前`。取实时活跃时刻，不是审计日志时间（审计可能长时间空档） |
| `el` | number | 否 | 本轮已运行秒数，`-1` 表示无。显示为大号耗时 |
| `cnt` | number | 否 | 计数数字，`-1` 表示不显示 |
| `csub` | string | 否 | `cnt` 的说明文字，如 `今日操作` |
| `sub` | string | 否 | 附加说明，显示在指标行 |
| `heat` | string | 否 | 24 小时活动强度，见下 |
| `cpu` | number | 否 | 处理器占用百分比，仅 `pc` 页使用 |
| `mem` | number | 否 | 内存占用百分比，仅 `pc` 页使用 |
| `disk` | number | 否 | 磁盘占用百分比，仅 `pc` 页使用 |
| `load` | number | 否 | 负载乘以 100 的整数，如 `330` 表示 3.30 |

### heat 字段

定长 24 字符的字符串，每位是 `0` 至 `9` 的字符，代表一个小时的活动强度
（按当日峰值归一化）。**最右一位是最近一小时**，向左依次回溯。

例：`000000000000011000009033`

- 前 12 位全 0：凌晨到中午无活动
- 第 13 至 14 位为 1：上午有过少量活动
- 末尾 `9033`：18 点最忙，19、20 点仍在活动

固件按强度决定竖条高度（0 为 3 像素灰条，1 至 9 为 `4 + v*2` 像素品牌色条），
基线对齐在 y=478。

## 回执

板子收到并解析成功后会回一行：

```
ACK <标识> <状态词> / <任务>
```

例：`ACK workbuddy 工作中 / 执行命令`

**只在状态描述变化时才回**，状态不变不重复发。这样既有链路健康的信号，
又不会把发送缓冲灌满。若要确认链路是否存活，看采集端的传输字节数是否增长，
或看屏幕上顶栏的 `LINK OK`。

## 超时与容错

| 情形 | 行为 |
|---|---|
| 单路 15 秒无数据 | 该页任务行改为「超过 15 秒未收到数据」，清空命令摘要 |
| 四路全部超时 | 顶栏 `LINK` 转红显示 `NO LINK` |
| 收到无法解析的行 | 直接丢弃，不打印（打印会占用发送缓冲，形成恶性循环） |
| 单行超过 255 字节 | 丢弃该行，重置缓冲区，避免半截 JSON 卡住解析 |

## 为什么不走控制台 UART

早期版本走 UART，遇到一个硬限制：**控制台接收环形缓冲只有 256 字节**。
采集端一轮写三条消息（约 270 字节）就会溢出，字节从中间被丢掉，两条消息拼成一行，
解析失败。当时的规避办法是把 JSON 压到 60 字节、三条之间错峰 0.5 秒发送——
能用，但属于绕开问题。

改用 USB CDC 后这个限制消失：TinyUSB 有流控，可以按任意节奏发送。
